    │  └────────────────────────────────────────────┘  │
    │  ┌────────────────────────────────────────────┐  │
    │  │ milo_agent:user:{id}:skills → {name: url}  │  │ ◀── skill 记录
    │  │ 持久化 ✅                                    │  │
    │  └────────────────────────────────────────────┘  │
    └──────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────┐
    │  MongoDB                                         │
    │  ┌────────────────────────────────────────────┐  │

    │  └────────────────────────────────────────────┘  │
    │  ┌────────────────────────────────────────────┐  │
    │  │ {DB}_store        → 长期记忆 /memories/    │  │ ◀── 用户偏好
    │  │ 持久化 ✅                                    │  │
    │  └────────────────────────────────────────────┘  │
    └──────────────────────────────────────────────────┘

    ┌──────────────────────────────────────────────────┐
    │  进程内存  (_agent_cache dict)                    │
    │  ┌────────────────────────────────────────────┐  │
    │  │ thread_id → agent 实例 + sandbox 引用      │  │ ◀── 热缓存
    │  │ ❌  重启丢失（但从 Redis/Redis 恢复 sandbox）│  │
    │  └────────────────────────────────────────────┘  │
